# Технические заметки

## Устаревший параметр Streamlit

В `app.py` параметр `use_container_width=True` используется в двух местах:

- таблица результатов (`st.dataframe`);
- кнопка скачивания Excel (`st.download_button`).

Streamlit предупреждает, что `use_container_width` устарел и будет удалён. При ближайшем обновлении заменить:

```python
use_container_width=True
```

на эквивалентный параметр:

```python
width="stretch"
```

Внешний вид и поведение элементов после замены измениться не должны. На момент создания этой заметки `app.py` не изменялся.
