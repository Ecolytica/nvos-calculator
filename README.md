# Калькулятор платы за выбросы Ecolytica

Автономное Streamlit-приложение для извлечения нормативов выбросов из файлов ПДВ и расчёта платы за негативное воздействие на окружающую среду по ставкам выбранного года.

## Возможности

- загрузка SpreadsheetML `.xls`, а также `.csv` и `.txt` с разделителем `;`;
- выбор года ставок платы;
- поиск ставки по четырёхзначному коду вещества;
- расчёт с коэффициентами Квр и Кпр;
- просмотр итогов и выгрузка результата в `.xlsx`.

## Добавление ставок нового года

Справочники находятся в `data/payment_rates.json`. Чтобы добавить год, создайте в объекте `years` новый раздел с полями `regulation` и `rates`. Коды веществ можно записывать без ведущих нулей — приложение автоматически приводит их к четырём знакам. После перезапуска новый год появится в списке автоматически.

## Запуск

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

Требуемая версия Python указана в `runtime.txt`. Интерфейс оформлен по дизайн-системе Ecolytica; стили находятся в `assets/ecolytica.css`.
