# Калькулятор платы за выбросы в атмосферу Ecolytica

Streamlit-приложение для переноса нормативов выбросов из файла программы ПДВ-Эколог и расчёта платы за негативное воздействие на окружающую среду.

## Возможности

- загрузка исходного файла ПДВ в формате SpreadsheetML `.xls` без предварительного редактирования;
- сопоставление позиций перечня № 2909-р с кодами ставок платы № 2409-р;
- выбор года и коэффициентов расчёта;
- расчёт платы по каждому веществу и общей суммы;
- выгрузка результатов в числовой файл `.xlsx` с фиксированной точностью.

Загруженный файл используется только для расчёта в текущем сеансе приложения и не сохраняется.

## Справочники

- `data/payment_rates.json` — ставки платы по кодам веществ и годам;
- `data/position_2909_to_rate_codes.json` — явное соответствие позиций распоряжения № 2909-р кодам ставок.

## Локальный запуск

Требуется Python 3.12.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
streamlit run app.py
```

## Использование

1. В программе ПДВ-Эколог выгрузите файл с нормативами выбросов и сохраните его без изменений как «Файл MS Excel (*.xls)».
2. Загрузите файл в калькулятор.
3. Выберите год ставок и коэффициенты.
4. Проверьте расчёт и скачайте результат в формате `.xlsx`.
